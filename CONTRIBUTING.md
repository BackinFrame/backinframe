# Contributing

Thanks for helping! Issues and pull requests are welcome, in English or Dutch.

- **Bugs:** include what you expected, what happened, and the relevant lines from
  `docker compose logs backinframe`. Remove topic names first.
- **Ideas:** open an issue before writing a large change, so we can agree on the approach.
- **Pull requests:**
  - keep them focused;
  - add or update tests;
  - make sure `pytest` and the ruff check from [docs/development.md](docs/development.md) pass;
  - put user-facing text in `src/backinframe/i18n.py`, in both languages.

Good first contributions:

- a Nextcloud or Immich source;
- Matrix or Telegram as an extra channel;
- offline place names from GPS;
- more languages.
